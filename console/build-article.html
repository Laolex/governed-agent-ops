The answer moved while the request stayed still.

An operations agent received the same request twice: quarantine whatever started failing after last night's configuration change. The operator, request bytes, code and policy were unchanged.

Between the runs, an unrelated process wrote one correction into shared memory. The first run resolved the request to invoice-classifier. The second resolved it to billing-reconciler.

That movement is ordinary for a memory-using agent. It is also difficult to investigate after the fact.

The missing boundary is identity, version and population.

Google's trace preserved the text injected into the prompt. The captured record did not name which Memory Bank resource supplied that text, which revision was current, or how many other memories were in scope and lost the top-k cut.

Governed Agent Operations records that boundary. The ADK agent reads the fleet and proposes an operation, but it has no write tool. A separate deterministic executor applies policy, performs the transition and appends a decision record.

Before writing, the executor constructs a retrieval manifest with the scope, population size, excluded count, memory identities, revision identities, content hashes and distances.

The first decision drew from three memories, selected all three and excluded none. The second drew from four, selected three and excluded one. The newly written revision entered at the closest distance and displaced the previous third result.

The record explains the changed target without pretending the model itself is deterministic.

The verifier refuses to overstate what the evidence proves.

A record with identities, population and a valid hash chain is BOUND_UNCORROBORATED. It says what the executor observed in scope.

It becomes BOUND only when an exported Google trace independently agrees with the manifest's content hashes. If trace and manifest disagree, the verifier reports UNBOUND. It does not average disagreement into a confidence score.

A four-arm ablation tests whether that distinction is load-bearing. Remove revision identities and the result becomes UNBOUND. Remove population and it becomes UNBOUND. Remove the manifest and it becomes NOT_CERTIFIED.

Two engines. One deterministic write boundary.

The deployed system uses Gemini 3.5 Flash through Google ADK on Vertex AI Agent Engine. Cloud Run serves the console and API. Firestore stores fleet state, operational facts and the transactionally appended hash chain. Memory Bank supplies persistent context, while Cloud Trace supplies independent prompt evidence for the strongest verification class.

The narrow claim matters: the platform trace shows the text that reached the prompt. Governed Agent Operations additionally records which versioned memory it came from, what population it was selected from and what lost.
